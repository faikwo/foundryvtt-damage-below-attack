# Damage Below Attack (FoundryVTT D&D5e Module)

This Foundry VTT module reorders the D&D5e item chat card so that **damage rolls appear below the attack roll**, matching the natural flow of roll to hit → roll damage.

## Features
- Moves the damage section below the attack roll
- Lightweight template override (no JavaScript)
- Fully compatible with core D&D5e
- Works alongside most automation modules

## Installation

In Foundry VTT:

1. Go to **Add-on Modules**
2. Click **Install Module**
3. Paste this Manifest URL: https://raw.githubusercontent.com/faikwo/foundryvtt-damage-below-attack/main/module.json
